# ModraUp for Windows · Privacy policy

Applies to the ModraUp Windows desktop application, version 0.8.0. Last updated November 25, 2026.

**Models and files.** ModraUp processes the models, drawings and textures you open on your device. You choose where to save or export them. If you use a shared or cloud-synced folder, the service you choose handles those files according to its settings.

**Updates and websites.** When ModraUp checks for a new version, it contacts GitHub to retrieve release information. GitHub receives connection information such as your IP address. When you open a website, an extension catalog or an embedded web page, that site's operator also receives a request. See the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) for how GitHub handles requests and content.

**Crash reports.** ModraUp stores diagnostic records on your device to help investigate failures. They can include application and operating system versions, graphics hardware details, startup stage and call stacks. You can review, edit, defer or discard a report. If you consent to sharing and open a GitHub issue draft, the draft text can be sent to GitHub in the URL. Longer reports are copied to your clipboard for you to paste. Submitting the issue makes your GitHub username and report visible publicly. Remove personal details before sharing. Windows memory dumps may contain sensitive data from process memory. You can export a dump separately and decide whom to share it with. The app's diagnostic cleanup removes expired local records when it runs, with a 30-day retention window. Exported copies and submitted GitHub issues are managed separately.

**Extensions and connected clients.** Ruby extensions may access models, files and network services. If you enable the local MCP server and authorize a client, the client can use the enabled tools to interact with your model. A client or extension may send data to its own provider. Check its settings and privacy policy before granting access.

**Contact.** To ask about personal information shared with the ModraUp developer or request its deletion, email modraup.com@gmail.com. If your request concerns a public report, include the issue link. Please send sensitive details privately.
